## Открытые вопросы для Айдара
- Цифры Wialon/Escort вендорские, сам отчёт Escort Group не найден. Если есть доступ к нему, стоит проверить выборку.
- Wialon Remote API и встроенные отчёты Wialon о заправках и сливах указаны по общим знаниям, документацию sdk.wialon.com в этой сессии открыть не удалось. Проверь на своём аккаунте, что токен только на чтение даёт доступ к сообщениям и датчикам.
- Где у клиентов в 1С для Казахстана живёт путевой лист: в 1С:Бухгалтерии для Казахстана, в отраслевой конфигурации по автотранспорту или только списание ГСМ актом? От этого зависит выгрузка.
- ЕСУТД: срок 1 июня 2027 уже дважды переносили. Перед публикацией сверить приказ № 189 на adilet.zan.kz; если будут поправки, обновить FAQ.
- Постановление № 1210 (нормы для госорганов): актуальная редакция не проверена, поэтому на странице оно только «ориентир».
- Цена дизеля 300 ₸ в ROI помечена как допущение; при желании подставить текущую розничную цену.
- Реальные поисковые запросы проверить не успели (лимит поиска), формулировки FAQ подобраны по типичным запросам «как выявить слив топлива», «электронный путевой лист», «нормы расхода ГСМ РК». Стоит сверить в Яндекс Вордстат или Google Search Console.
